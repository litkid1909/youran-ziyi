# 悠然字逸 Youran Ziyi
「悠然字逸」是基於[辰宇落雁體](https://github.com/Chenyu-otf/chenyuluoyan_thin)的開放原始碼中文字型。與原作者的版本，主要差異是另外新增中文字和符號，並調整部份文字的寫法。可以免費商用，歡迎大家自由應用、自由優化、自由改作！

## 附註
* 補的缺字，效果差強人意，聊勝於無。
